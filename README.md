# HR Anomaly Frontend

Frontend architecture for the HR Anomaly Management backend.

## Stack

- React 19
- Vite
- TypeScript
- TailwindCSS
- shadcn/ui
- Lucide React
- Axios
- AG Grid Community

## Scripts

```bash
npm install
npm run dev
npm run build
```

This scaffold intentionally contains no business logic and no backend API calls.
